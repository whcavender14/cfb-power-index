# What the site cannot show (and why)

| Feature / field | Status | Reason | What would fix it |
|---|---|---|---|
| CFPi+ ratings for weeks 1–2 of 2026 | Shown as reconstructions (hollow points, labelled) | CFPi+ went live at week 3; weeks 1–2 were published by EB_features and are never mixed in. The reconstruction re-runs the unchanged model at each cutoff on the play-by-play pulled on 2026-09-25, so a CFBD correction made after those weeks would be reflected. The script's guard reproduces published week 3 exactly. Week-3 movement compares against reconstructed week 2. | From week 4 on, every point is a published archive. |
| Rating history for earlier seasons | No season selector | No CFPi+ ratings were published for 2025 or earlier, so any prior-season line would be a reconstruction on different frozen inputs and not comparable. | Reconstruct a past season with a documented freeze, if wanted. |
| Player starters, depth charts, snap counts | Not shown | CFBD has none of these. The team page shows statistical leaders (season totals by fixed rules), which says nothing about who starts. | A depth-chart source. |
| EPA (offense, defense), success rate and other efficiency stats | Not shown | Not in the production model output. Success rate is a C2 input (built from play-by-play inside the ratings step) but is not saved to the snapshot, and EPA is not used at all. Adding either on the site would mean computing new statistics outside the model. | Save per-team success rate (and, if wanted, EPA) in the ratings snapshot. That touches production files, so it needs your approval. |
| Pregame projections for games already in the ratings, beyond one week back | Only in "What changed" | The explanation uses the comparison week's ratings, which exist only for weeks in `history.json`. | A weekly pre-kickoff prediction archive. |
| TV network | Omitted | Not in any pulled data (CFBD `/games/media` is not fetched). | Add a media pull to the pipeline. |
| Betting lines beyond the upcoming week; line movement; opening/closing lines | Omitted | `betting.json` holds one quote per game at retrieval time for the upcoming week only. | Archive lines per game at fixed times. |
| Model-vs-market difference on the new Games page | Omitted | That would be a new browser-side calculation. The legacy `/betting/` page still shows it (computed in the browser, a known Rule 2 exception kept to preserve the feature). | Export model-vs-market in R, then retire the browser calculation. |
| Results of games played since the ratings cutoff | Shown as scheduled, with projection | The site reflects what the model has seen (results before the Monday cutoff). A note on the Games page says so. | Next weekly run. |
| Pregame projections for completed games | Omitted | Only current ratings exist, and showing them as a pregame line would be misleading. | A weekly pre-kickoff prediction archive (see `ARCHITECTURE.md` §7). |
| Records, schedules and game projections when the simulation fails | Hidden ("—") | These come from the schedule stored in the simulation output (`sim$schedule`). Ratings still show. | Export the schedule from the ratings step as well. |
| Conference championship games | Not simulated | Season simulations use regular-season records only. Conference championship games are not simulated; standings leaders are designated champions. Records, projected wins, conference-title odds and playoff odds all follow from this. | Model enhancement: see `TODO.md`. |
| Bowl games and bowl projections | Not modeled | The simulation covers the regular season and the CFP only. | Out of scope for the model. |
| Preseason projected wins and Vegas win totals | Omitted | No archived preseason simulation or Vegas CSV exists (null in `simulations.json`). | Archive them before next season. |
| "Most likely bracket" PNG on `/simulations/` | Legacy approximation | Still built in the browser from aggregate odds (`src/playoff.ts`). The new Playoff page uses the exported representative field instead. | Switch the PNG to `playoff.json` (planned shareable-PNG stage). |
| Scenario conditions beyond game winners | Not available | The What-if page can condition only on who wins a remaining game. Margins, conference title games (not simulated) and results after the ratings cutoff that would change ratings are out of reach. With 1,000 simulations, a few picks leave few matching seasons. | More simulations (a production config change). |
